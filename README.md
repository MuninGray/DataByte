# Sistema de Gestión de Residuos Urbanos

Proyecto desarrollado como trabajo de **3.º año de Educación Media Tecnológica en Informática** de **ESI Buceo (UTU)**.

## Descripción

DataByte es un sistema web diseñado para mejorar la gestión de residuos urbanos, permitiendo administrar establecimientos, municipios, cuadrillas, contenedores y maquinaria de forma centralizada.

El objetivo del proyecto es optimizar el seguimiento de las tareas de recolección, facilitar la administración de los recursos y proporcionar una plataforma eficiente para la gestión ambiental.

## Funcionalidades

- Registro e inicio de sesión de usuarios.
- Gestión de permisos y roles.
- Administración de establecimientos.
- Gestión de municipios.
- Administración de cuadrillas.
- Gestión de contenedores.
- Administración de maquinaria.
- Control y seguimiento de las operaciones.
